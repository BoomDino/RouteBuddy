How the project works

CabPool is a local, menu-driven Python prototype. It takes ride requests, looks for groups that can share a vehicle, calculates an even fare split, and saves the information between runs.

01

Enter ride requests

For each traveler, enter a name, destination, preferred departure time, and flexibility from 0 to 360 minutes. The program validates these values before adding the request. Times can use 24-hour format or AM/PM.

02

Build a group

When you choose “Match and show results,” CabPool separates requests by destination and sorts each destination by preferred time. It starts with the earliest unassigned request, then adds people whose available time windows overlap. The group's shared window narrows with each person added, and no cab exceeds four passengers.

03

Choose a departure time

The suggested departure is the midpoint of the time window shared by everyone in that cab. The matcher accounts for windows that cross midnight, so a late-night request can match an early-morning request when their flexibility allows it.

04

Split the fare

The prototype uses a fixed fare of Rs. 600 per cab and divides it equally among the passengers. Savings are estimated against each passenger booking a separate Rs. 600 cab.

fare per person = Rs. 600 ÷ passengers
savings for the group = (passengers − 1) × Rs. 600

For example, four passengers pay Rs. 150 each, saving Rs. 450 each compared with travelling alone.

05

Review matches and unmatched requests

Results list each cab's destination, departure and shared window, passengers, per-person fare, and savings. Requests that cannot join a group of at least two are listed as unmatched.

06

Keep data between runs

Ride requests are saved in requests.csv and loaded when the program starts. After matching, the cab groups and summary are saved in results.json. Both files are created in the directory where the program runs.

Five parts of the program

Input and validation
Collects and checks each ride request.

Matching engine
Greedily groups requests by destination and overlapping time windows.

Fare calculator
Calculates each passenger's share and estimated savings.

File storage
Loads requests from CSV and saves requests and results.

Output display
Prints cab details, unmatched requests, and total savings.

Run CabPool

Install Python 3, download or clone the repository, then start the program from its folder. No third-party packages are needed.

python3 cabpool_5_methods.py

Choose 1 to add requests, 2 to review them, 3 to match and display results, or 0 to exit.

Prototype assumptions

CabPool is a command-line demonstration of ride matching. It assumes a fixed Rs. 600 fare per cab, capacity of four, exact destination names after capitalization, and local CSV/JSON storage. Its greedy matching is intended for small groups of student requests; it does not book vehicles or contact passengers.
