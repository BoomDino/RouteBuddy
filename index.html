A simple ride matching prototype

Make the trip together.

CabPool helps hostel students heading to the same station or airport find a shared cab, coordinate departure times, and split the fare.

Explore the code How to run it

How it works

Share a request

Enter a destination, preferred departure time, and how flexible you can be.

Find a common window

CabPool groups requests with the same destination and overlapping time windows.

Split the fare

See the suggested departure, passenger list, per-person share, and estimated savings.

Built for a clear first step

This Python command-line prototype uses a greedy matching algorithm and stores requests and results locally in CSV and JSON files. Its default model assumes four seats and a sample fare of Rs. 600 per cab.
